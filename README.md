# udp-chat-app
UDP Chat App

This is a very basic version of a UDP chat app.
To run, open a terminal, navigate to this project folder, and type "go run server.go".
Then open several other terminals and type "go run client.go".
Now, any messages you type in one of the client terminals will be broadcasted to all other terminals.

This app is still being developed. Upcomming additions include timestamps and testing features.
